## 重新执行

按 README 安装开发测试依赖后，在 Windows PowerShell 中执行：

```powershell
$env:TEST_BROWSER_CHANNEL = 'chrome'
$env:VERIFY_WORD = '1'
node tests/run.cjs all
```

`VERIFY_WORD=1` 需要本机安装 Word。此模式启动独立的普通 Chrome 测试窗口并将其放在屏幕外，以使用真正的系统剪贴板；无头浏览器的内部剪贴板无法完成跨应用验证。测试结束会关闭此浏览器和新建的 Word 测试文档。测试会将样例表格写入系统剪贴板。
