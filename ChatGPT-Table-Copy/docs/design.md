# ChatGPT 表格复制：设计

日期：2026-10-31

目标：ChatGPT 网页中的每张对话表格上方右侧出现一个“复制表格”按钮，点击后可粘贴为 Word 可编辑表格。

选择：使用 Manifest V3 内容脚本，仅匹配 https://chatgpt.com/* 和 https://chat.openai.com/*。相比纯文本复制，它保留单元格结构；相比生成 Word 文件，它保持用户要求的一键复制流程。

复制：创建独立、经过白名单过滤的 HTML 表格，同时提供制表符分隔的纯文本。保留合并单元格、粗体、斜体、下划线、链接、列表、换行。统一黑字、白底、灰色表头和细边框。只复制当前表格，不复制网页操作按钮、脚本、图片和追踪属性。链接只允许 http、https、mailto。

界面：不重建或包裹网站表格；在最近的独立表格滚动容器前插入独立工具条。观察新增或替换的表格，防止重复按钮，清理失效工具条。按钮支持键盘、深浅色和屏幕阅读器状态提示。

权限与数据：仅 clipboardWrite；不申请剪贴板读取权限，不上传、保存聊天数据，不调用远程脚本、接口或模型。

异常：现代 HTML 剪贴板不可用时，通过 copy 事件写入同样的 HTML/文本格式；仍失败则显示重试提示，绝不将纯文本成功冒充表格复制成功。

验证：真实 Chromium 加载扩展，在本地替代响应中覆盖动态表格、宽表、页面替换、重复注入、暗色、失败分支；读取测试剪贴板并粘贴到富文本编辑区域。若 Word 自动化可用，以 Word 导入/粘贴验证结构。真实 ChatGPT 登录页和 Word 的全部版本未被这些模拟页面测试覆盖。
